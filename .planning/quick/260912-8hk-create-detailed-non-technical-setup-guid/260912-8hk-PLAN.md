# Quick Task: Create Detailed Non-Technical Setup Guide (SETUP.md)

## Goal
Write a comprehensive, friendly, step-by-step setup and usage guide in `SETUP.md` specifically tailored for non-technical users and administrators deploying OpenMail on shared cPanel hosting or VPS.

## Tasks

### Task 1: Draft SETUP.md
- Introduction to OpenMail and the zero-CLI WordPress-style philosophy.
- Prerequisites (PHP 8.2+, MySQL/MariaDB, cPanel File Manager, IMAP/SMTP mail server credentials).
- Detailed Step 1: Uploading and extracting the deployment zip in cPanel File Manager.
- Detailed Step 2: Configuring Document Root to `/public` (with fallback `.htaccess` solution for hosts that lock primary domains to `public_html`).
- Detailed Step 3: Creating the MySQL database and user in cPanel.
- Detailed Step 4: Checking directory permissions (`storage/`, `bootstrap/cache/`).
- Detailed Step 5: Walking through each screen of the 8-step browser-based Setup Wizard (`/install`).
- Detailed Step 6: Post-installation & User Guide (logging in, managing emails, compose, labels, contacts, signatures).
- Troubleshooting & Common Questions (500 errors, database connection issues, IMAP/SMTP port and SSL troubleshooting, how to restart setup if needed).

### Task 2: Verification
- Verify `SETUP.md` is formatted cleanly, all steps are accurate to OpenMail's actual codebase and views, and explanations are beginner-friendly.
