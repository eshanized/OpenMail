## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → Settings UI | Authenticated user modifies own profile, signatures, preferences |
| User → Composer | Authenticated user composes emails with signature insertion |
| Browser → Session Revoke | User revokes own other sessions via Security tab |
| Signature Content → Renderer | User-created signature HTML rendered in composer/emails |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-17 | Tampering | Signature XSS | high | mitigate | Tiptap JSON stored; rendered via tiptap-php → HTMLPurifier → DOMPurify pipeline (reuse MessageSanitizer) |
| T-05-18 | Elevation of Privilege | Signature access control | low | mitigate | Signatures scoped to user_id; SignatureService checks ownership; Livewire components auth-gated |
| T-05-19 | Tampering | Session revocation bypass | medium | mitigate | SecurityTab only shows sessions for auth()->id(); revoke deletes by session ID with user_id check |
| T-05-20 | Information Disclosure | Session list exposes other users | low | mitigate | Sessions query filtered by user_id; no cross-user access |
| T-05-21 | Tampering | Mail preference injection | low | mitigate | SettingsRequest validates enums for page_size/default_folder/reply_behavior; Setting::set() scopes to user |
| T-05-22 | Denial of Service | Signature modal DoS | low | accept | Modal is Livewire component; rate limited by api.settings limiter |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package legitimacy audit completed; all packages [OK] |
