## Phase 4 Specific Component Contracts

### 1. Search System

#### 1.1 Search Bar (Top Toolbar)
- **Location**: Fixed top toolbar above message list, full width minus sidebar
- **Trigger**: Keyboard shortcut `/` focuses search input
- **States**: Default → Focused (blue ring) → Loading (spinner in input) → Results Dropdown Open
- **Dropdown**: Absolute positioned, max-h-96 overflow-auto, z-50, shadow-xl
- **Dropdown Items**: 8 max, each with sender, subject (highlighted), snippet (highlighted), folder badge, date
- **Navigation**: Arrow keys navigate, Enter opens message, Escape closes
- **Footer**: "View all results" link → navigates to `/search` page with query preserved

#### 1.2 Search Results Page (`/search`)
- **Layout**: Two-column (filter sidebar 280px + results list)
- **Filter Sidebar**: Folder select, Date range (presets: Today, Week, Month, Year + Custom), Has attachment toggle, Read/Unread/Flagged radios, Label multi-select
- **Active Filters**: Displayed as removable chips above results list
- **Results**: Same row structure as message list but with highlighted snippets
- **Pagination**: Standard Laravel pagination at bottom
- **Empty State**: Centered illustration + copy from Copywriting Contract

#### 1.3 Search Highlighting
- **Implementation**: Scout highlighting → wrap matches in `<mark class="bg-yellow-100 text-yellow-900 px-0.5 rounded">`
- **Sanitization**: Highlights applied AFTER DOMPurify on snippets
- **Scope**: Subject, snippet, sender name/email in results

### 2. Threading System

#### 2.1 Thread Row (Collapsed)
- **Height**: 56px (py-3) — denser than flat message row (64px)
- **Structure**: Checkbox | Star | Sender (latest) + Unread Dot | Subject + Label Chips (max 3) | Date | Attachment | Expand Chevron
- **Unread Badge**: Blue circle with count (if >1 unread in thread)
- **Label Chips**: Horizontal, max 3, then "+N" chip with popover
- **Hover**: bg-gray-50, chevron color changes to gray-600
- **Active Thread**: bg-blue-50 border-l-2 border-blue-600 (when message opened)

#### 2.2 Thread Expansion (Inline)
- **Trigger**: Click anywhere on thread row (except checkbox/star/label chips)
- **Animation**: Alpine.js x-transition, 150ms ease-out, max-h collapse/expand
- **Expanded Content**: Child messages in chronological order (oldest first), each as compact row
- **Child Row**: Reduced padding (py-2), no checkbox, indented 12px, shows sender, subject, date, snippet
- **Load More**: If thread > 10 messages, show "Load 10 more" button at bottom
- **Keyboard**: Space/Enter toggles, Arrow Right expands, Arrow Left collapses

#### 2.3 Thread Toggle Button
- **Location**: Message list toolbar, next to Sort controls
- **Icon**: Chat bubbles stacked (threaded) ↔ Single chat bubble (flat)
- **States**: Active = blue-600 + bg-blue-50, Inactive = gray-600
- **Persistence**: localStorage key `openmail:threadMode:{folderPath}` → "threaded" | "flat"
- **Default**: "threaded" for Inbox, "flat" for Sent/Drafts/Trash/Spam

### 3. Contacts System

#### 3.1 Contacts Sidebar Panel (Tab: "Contacts")
- **Tab Bar**: Three tabs — Folders | Contacts | Labels — at top of sidebar
- **Mobile**: Tabs become bottom navigation on <768px (fixed bottom, safe-area-inset)
- **Panel Header**: "Contacts" + "New Contact" button (blue-600, plus icon)
- **Search**: Inline search input (debounced 200ms) filters contact list
- **Contact Row**: Avatar (initial, colored bg from hash), Name, Email, Phone (icon + truncate), Groups (max 2 chips + overflow)
- **Actions**: Click row → opens Contact Detail modal; Hover → shows Edit/Delete icons
- **Empty State**: Illustration + copy + "Add Contact" / "Import vCard" buttons

#### 3.2 Contact Detail Modal
- **Size**: max-w-md, centered
- **Fields**: Name (required), Email (required, validated), Phone, Notes (textarea), Groups (multi-select chips)
- **Avatar**: Auto-generated from name initials, colored background
- **Actions**: Save (primary), Cancel (secondary), Delete (destructive, bottom-left)
- **Validation**: Inline field errors, email format, duplicate email check

#### 3.3 Contact Import/Export Modal
- **Import**: Drag-drop zone + file input, accepts .vcf/.vcard
- **Preview**: Parsed contacts list with checkboxes (all checked by default), show conflicts (existing email)
- **Conflict Resolution**: Skip / Update existing / Create duplicate
- **Export**: Button triggers .vcf download of all contacts (vCard 3.0)

#### 3.4 Composer Autocomplete Integration
- **Source**: Merged local contacts + ContactAutocompleteCache (IMAP recipients)
- **Ranking**: Local contacts first (exact match > prefix match), then IMAP cache (frequency desc)
- **Deduplication**: By email (case-insensitive), local wins
- **Display**: Same as existing recipient chips dropdown (avatar initial, name, email, frequency badge)

### 4. Labels System

#### 4.1 Labels Sidebar Panel (Tab: "Labels")
- **Panel Header**: "Labels" + "Create Label" button
- **Label Row**: Color dot (12px), Name, Unread Count Badge (blue), Total Count (gray), Hover → Edit/Delete icons
- **Drag Reorder**: Not in v1 (deferred)
- **Click Label**: Filters message list to that label (URL: `/labels/{labelId}`)
- **Active Label**: Highlighted in sidebar (blue-50 bg, blue-700 text, left border)
- **Empty State**: Illustration + copy + "Create Label" button

#### 4.2 Create/Edit Label Modal
- **Fields**: Name (required, unique per user), Color Picker (10-color palette grid)
- **Color Picker**: 2x5 grid, selected has white ring + checkmark, accessible names via aria-label
- **Validation**: Name required, max 50 chars, unique (case-insensitive)
- **Actions**: Create/Save (primary), Cancel (secondary)

#### 4.3 Label Chips (Message List & Thread Rows)
- **Style**: Pill shaped, px-2 py-0.5, text-xs, font-medium, rounded-full
- **Colors**: Use label's assigned color for bg, white text (ensured contrast)
- **Max Display**: 3 chips horizontally, then "+N" chip (gray-100 bg, gray-600 text)
- **Overflow Popover**: Click "+N" → popover with all label chips, click to filter
- **Interaction**: Click chip → filters to that label (navigates to `/labels/{labelId}`)

#### 4.4 Inline Label Management (Sidebar)
- **Hover Row**: Shows pencil (edit) and trash (delete) icons
- **Right-Click**: Context menu — Rename, Change Color, Delete
- **Keyboard**: Enter on label row → edit mode, Escape → cancel, Delete key → confirm delete

#### 4.5 Archive Action
- **Toolbar Button**: Archive icon (box with arrow down), tooltip "Archive (e)"
- **Keyboard Shortcut**: `e` key (when message list focused)
- **Behavior**: 
  1. IMAP MOVE message to Archive folder (\Archive SPECIAL-USE or "Archive" heuristic)
  2. Remove "Inbox" label if present
  3. Add "Archive" label if exists, else create it
  4. Update message list optimistically
- **Undo**: Toast appears for 5s with "Undo" button → reverses IMAP move and labels
