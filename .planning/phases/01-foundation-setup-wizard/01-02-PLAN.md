<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Wizard | Form submissions with DB creds, IMAP passwords, admin password. All via Livewire. |
| Wizard → .env | Writing credentials to disk. Must preserve existing keys, never expose. |
| Wizard → IMAP Server | Connection testing with user-provided credentials. Must use TLS. |
| Wizard → SMTP Server | Connection testing. Must not send email (D-08). |
| Wizard → Database | Running migrations, creating admin account. Must use DB creds from step 3. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Information Disclosure | IMAP password in .env | high | mitigate | Passwords written to .env only; never logged; .env in .gitignore |
| T-02-02 | Tampering | .env file corruption | high | mitigate | Structured .env writer preserves existing keys; never overwrites APP_KEY |
| T-02-03 | Information Disclosure | IMAP password in session | medium | mitigate | Per research: encrypt with Crypt::encrypt() before session storage; never write to DB |
| T-02-04 | Elevation of Privilege | Wizard bypass after install | high | mitigate | storage/installed lock file; flock() for atomicity (per pitfall 4) |
| T-02-05 | Tampering | CSRF on wizard forms | medium | mitigate | @csrf on all forms; Livewire handles CSRF automatically |
| T-02-06 | Denial of Service | IMAP connection timeout | low | mitigate | 10-second timeout on IMAP client (per pitfall 3) |
| T-02-07 | Information Disclosure | SMTP test sends email | medium | mitigate | Per D-08: connection-only test; SmtpTransport::checkConnection(), never send() |
</threat_model>
