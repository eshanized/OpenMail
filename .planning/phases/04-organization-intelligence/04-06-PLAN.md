<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Search Query → Backend | Search query string from user input; must be sanitized for MySQL FULLTEXT boolean mode |
| Search Results → Client | Message snippets rendered in dropdown/page; must be sanitized (DOMPurify) before highlight injection |
| Filter Parameters → Backend | Folder, date, label filters from URL params; validated server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-06 | Injection | Search query (FULLTEXT boolean mode) | high | mitigate | Escape boolean operators (+ - > < * ") in user query before passing to MATCH...AGAINST; use parameter binding (done in Plan 2) |
| T-04-07 | XSS | Search snippet highlighting | high | mitigate | Apply DOMPurify to snippet BEFORE wrapping matches in <mark>; never trust raw message content (verified in Task 3) |
| T-04-08 | Info Disclosure | Search results cross-user | medium | mitigate | SearchService always scopes to authenticated user_id; per-user Scout index isolation |
| T-04-09 | DoS | Expensive search queries | low | mitigate | Scout database engine paginates; limit instantSearch to 8 results; max page size 50 |
| T-04-10 | Tampering | Filter parameter manipulation | low | mitigate | Validate folder exists for user; date ranges sanitized; label IDs verified owned by user |
</threat_model>
