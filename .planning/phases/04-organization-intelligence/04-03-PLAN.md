<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Input → Contact CRUD | Name, email, phone, notes from user; validated server-side |
| vCard File → Import Parser | Uploaded .vcf files parsed by sabre/vobject; malformed files handled gracefully |
| Composer Autocomplete → Backend | Search queries from composer; sanitized before query |
| IMAP Recipient Cache → Autocomplete | Cached recipients from sent mail; read-only merge |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-11 | Injection | vCard import parsing | medium | mitigate | sabre/vobject handles parsing; wrap in try/catch; validate parsed email format before DB insert |
| T-04-12 | Info Disclosure | Contact autocomplete cross-user | low | mitigate | searchUnified() scopes to authenticated user_id; IMAP cache also user-scoped |
| T-04-13 | Tampering | Contact email uniqueness bypass | medium | mitigate | Unique index on (user_id, email) at DB level; server-side validation before insert/update |
| T-04-14 | DoS | Large vCard import | low | mitigate | Limit import to 1000 contacts per request; chunk processing; file size validation (max 2MB) |
| T-04-15 | Spoofing | IMAP recipient cache pollution | low | accept | Cache populated only from sent mail (user's own actions); not from received mail |
</threat_model>
