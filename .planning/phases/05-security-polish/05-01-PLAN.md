## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Laravel (HTTP) | Untrusted client requests hit routes, middleware, controllers |
| Browser → CSP Violation Endpoint | Automated browser reports POST violation JSON (no auth) |
| Laravel → Database | Trusted application writes audit logs, settings |
| Laravel → IMAP/SMTP | Trusted application connects to mail server with user credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | CSP nonce generation | high | mitigate | Use spatie/laravel-csp Vite nonce generator; nonces are cryptographically random per-request; verify in test |
| T-05-02 | Tampering | CSP violation reports | medium | mitigate | Throttle /csp-report at 60/min/IP; log only, no reflection; validate JSON structure before logging |
| T-05-03 | Spoofing | Audit log injection | low | mitigate | AuditService::log() called only from trusted server code (LoginController, ComposerService); no user input in event_type/description |
| T-05-04 | Information Disclosure | Audit log PII exposure | medium | mitigate | AuditService excludes passwords; IMAP password encrypted in session; log channel 'security' separate from default |
| T-05-05 | Denial of Service | Audit log table growth | medium | mitigate | 90-day retention via scheduled PruneAuditLogs command; indexes on created_at for efficient deletion |
| T-05-06 | Tampering | CSP bypass via unsafe-inline | high | mitigate | Report-only mode first; monitor violations; only Livewire/Alpine fallback uses unsafe-inline; documented for removal |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package legitimacy audit completed in RESEARCH.md; all packages [OK]; no new installs in this phase |
