**Step 3: FolderMapper service (D-01)**

Create `app/Services/FolderMapper.php`:
- Constant `ROLE_MAP`: maps IMAP SPECIAL-USE attributes to role strings: `\Inbox` → `inbox`, `\Sent` → `sent`, `\Drafts` → `drafts`, `\Trash` → `trash`, `\Junk` → `spam`, `\Archive` → `archive`
- Constant `NAME_HEURISTICS`: maps lowercase name substrings to roles: `inbox` → `inbox`, `sent` → `sent`, `drafts` → `drafts`, `trash` → `trash`, `spam`/`junk` → `spam`, `archive`/`archiv` → `archive`
- Method `mapFolderRole(Folder $folder): ?string`: checks `$folder->attributes` for SPECIAL-USE flags first, falls back to name heuristics. Returns null for custom folders.
- Method `mapFolderName(Folder $folder): string`: returns display name (e.g., "INBOX" → "Inbox", "Sent Mail" → "Sent Mail")

**Step 4: MessageSanitizer service (D-10)**

Create `app/Services/MessageSanitizer.php`:
- Method `sanitizeHtml(string $html): string`: configures HTMLPurifier with email-safe settings:
  - Allow: `<p>`, `<br>`, `<a>`, `<img>` (with src only), `<table>`, `<tr>`, `<td>`, `<th>`, `<div>`, `<span>`, `<h1>`-`<h6>`, `<ul>`, `<ol>`, `<li>`, `<blockquote>`, `<pre>`, `<code>`, `<strong>`, `<em>`, `<u>`, `<s>`, `<sub>`, `<sup>`
  - Strip: `<script>`, `<iframe>`, `<object>`, `<embed>`, `<form>`, `<input>`, `<button>`, `<style>`, `<link>`, `<meta>`, `<base>`
  - CSS: Allow safe properties (color, background-color, font-size, font-family, text-align, margin, padding, border)
  - Images: Allow `src` with `http/https` schemes only (block `data:`, `javascript:`)
  - Links: Allow `href` with `http/https` schemes only, add `rel="nofollow noopener"` and `target="_blank"`
  - Character encoding: UTF-8
- Method `sanitizeText(string $text): string`: plain text escaping with `e()` helper
- Method `blockRemoteImages(string $html): string`: rewrites `<img src="http...">` to `data-src` attribute for deferred loading (D-11)

**Step 5: ImapMailboxService (D-05, D-06, D-07)**

Create `app/Services/ImapMailboxService.php`:
- Private method `getClient(): Client`: creates fresh IMAP connection per request (per research anti-pattern). Uses `config('openmail.imap.*')` for host/port/encryption, `auth()->user()->email` for username, `Crypt::decrypt(session('openmail:imap_password'))` for password. Sets timeout to 10s, validate_cert true.
- Method `getFolders(): array`: connects, gets `$client->getFolders()`, maps each through FolderMapper, examines each folder for EXISTS/UIDVALIDITY, disconnects. Returns array of `['path', 'name', 'role', 'total', 'uidvalidity', 'has_children', 'parent_path']`.
- Method `getMessages(string $folderPath, string $sortBy = 'date', string $sortDir = 'desc', int $page = 1, int $perPage = 25): LengthAwarePaginator`: connects, gets folder, builds query with `setFetchBody(false)` (D-06), applies SORT via `setFetchOrderDesc()`/`setFetchOrderAsc()` (D-05, D-08), applies search criteria, paginates with `paginate(per_page: $perPage, page: $page)`. Disconnects.
- Method `getMessage(string $folderPath, int $uid): ?Message`: connects, fetches single message by UID with full body (D-06 for viewer in Plan 02). Returns message object.
- Method `getMessageCount(string $folderPath): array`: connects, examines folder, gets UNSEEN count. Returns `['total' => int, 'unread' => int, 'uidvalidity' => int]`.
- Method `moveMessages(string $folderPath, array $uids, string $destinationPath): bool`: connects, uses IMAP COPY + STORE \Deleted (D-17).
- Method `deleteMessages(string $folderPath, array $uids): bool`: moves to Trash folder (D-07 \Seen flag handling).
- Method `setFlag(string $folderPath, array $uids, string $flag, bool $value): bool`: IMAP STORE +FLAGS or -FLAGS for \Seen, \Flagged.
- Method `createFolder(string $name, string $parentPath = ''): bool`: IMAP CREATE (D-03).
- Method `renameFolder(string $oldPath, string $newName): bool`: IMAP RENAME (D-03).
- Method `deleteFolder(string $folderPath): bool`: IMAP DELETE (D-03).
- All methods must call `$client->disconnect()` in a finally block to prevent connection leaks.
