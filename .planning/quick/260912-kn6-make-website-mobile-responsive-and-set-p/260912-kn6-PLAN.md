# Quick Task: 260912-kn6 — Mobile Responsiveness & Coral Red Primary Color

## Description
Make the OpenMail website responsive to mobile devices across layouts, navigation, email lists, composer, settings, and setup wizard, and update the primary color to Coral Red in both light and dark modes.

## Tasks

### Task 1: Update Primary Color to Coral Red in Both Light and Dark Modes
- **Files**: `resources/css/app.css`
- **Action**:
  - Update semantic tokens in `@theme`:
    - `--color-primary`: `#cf4234` (Coral Red, WCAG AA compliant on light surfaces)
    - `--color-primary-hover`: `#b83326`
    - `--color-primary-subtle`: `#fdf2f0`
    - `--color-accent`: `#cf4234`
    - `--color-accent-subtle`: `#fdf2f0`
    - `--color-selected`: `#fdf2f0`
  - Update semantic tokens in `:where(.dark)`:
    - `--color-primary`: `#f87168` (Luminous Coral Red for dark backgrounds)
    - `--color-primary-hover`: `#ff857c`
    - `--color-primary-subtle`: `rgba(248, 113, 104, 0.12)`
    - `--color-selected`: `rgba(248, 113, 104, 0.10)`
  - Update rgba accent references in `.setup-callout-info` and `.email-control-btn.active` to match Coral Red.
- **Verify**: Inspect `app.css` and build assets with `npm run build`.

### Task 2: Fix Mobile Navigation and Drawer in Mailbox Layout
- **Files**:
  - `resources/views/layouts/app.blade.php`
  - `resources/views/layouts/mailbox.blade.php`
  - `resources/views/livewire/mailbox/folder-sidebar.blade.php`
- **Action**:
  - In `app.blade.php`: add `@yield('mobile-nav-toggle')` / slot in the top navigation header on mobile (`lg:hidden`) next to brand logo so navigation is always accessible without blocking page content.
  - In `mailbox.blade.php`:
    - Remove the awkwardly floating `fixed top-14 left-3` toggle button that covered titles and back buttons.
    - Wire `@section('mobile-nav-toggle')` to dispatch or toggle `sidebarOpen`.
    - Remove the rogue horizontal flex item `<div class="md:hidden h-16"></div>`.
    - Use `h-[calc(100vh-2.75rem)] h-[calc(100dvh-2.75rem)]` for mobile viewport sizing.
  - In `folder-sidebar.blade.php`:
    - Unhide the top switcher tabs on mobile (`block` instead of `hidden md:block`) so Folders, Contacts, and Labels are immediately switchable at the top of the mobile drawer.
    - Remove the broken `md:hidden fixed bottom-0` navigation that was trapped inside the hidden drawer.
    - When clicking folders or labels on mobile, dispatch or trigger drawer close so the message list is revealed immediately.
- **Verify**: Check layout structure and mobile drawer behavior.

### Task 3: Mobile Responsiveness for Message Lists, Viewer, Composer, and Settings
- **Files**:
  - `resources/views/livewire/mailbox/message-row.blade.php`
  - `resources/views/components/mailbox/thread-row.blade.php`
  - `resources/views/livewire/mailbox/message-list.blade.php`
  - `resources/views/livewire/mailbox/composer.blade.php`
  - `resources/views/livewire/settings/settings-page.blade.php`
  - `resources/views/components/email-renderer.blade.php`
  - `resources/views/setup/steps/*.blade.php`
- **Action**:
  - `message-row.blade.php` & `thread-row.blade.php`:
    - Adapt to mobile screens (`< sm`): stack into clean multi-line layout with Sender + Date on top, Subject below, snippet and tags under that, with comfortable tap targets (>= 44px) and full row tap-to-open.
    - Maintain 1-line table row on `sm:` screens and wider.
  - `message-list.blade.php`:
    - Make search bar stretch responsive on mobile (`flex-1 sm:w-60`).
    - Adjust action buttons and spacing to avoid awkward wraps.
  - `composer.blade.php`:
    - Full screen on mobile (`fixed inset-0 sm:inset-auto sm:m-auto sm:max-w-4xl sm:max-h-[92vh] sm:rounded sm:border`).
    - Make Tiptap toolbar scrollable horizontally on mobile (`overflow-x-auto`) to avoid taking up the whole screen height.
  - `settings-page.blade.php`:
    - Make settings categories horizontally scrollable pills on mobile (`flex lg:flex-col overflow-x-auto`) so the settings forms are immediately visible below tabs.
  - `email-renderer.blade.php`:
    - Add responsive iframe padding for mobile screens.
  - `setup/steps/*.blade.php`:
    - Change `p-8 sm:p-12` to `p-4 sm:p-8 md:p-12`.
- **Verify**: Run `npm run build` and `php artisan test`.
