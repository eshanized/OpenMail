## Phase 3 Specific Design Notes

### Composer Modal (D-01, D-03)
- **Trigger**: "Compose" button in mailbox toolbar → opens modal overlay
- **Size**: `max-w-4xl w-full mx-auto` (896px max), vertically centered, `max-h-[90vh] overflow-y-auto`
- **Backdrop**: `fixed inset-0 bg-black/50 z-40` with `@click.outside="close"` + Escape key
- **Header**: "New Message" / "Reply" / "Forward" title + Cancel (secondary) + Save Draft (secondary) + Send (primary)
- **Sections** (top to bottom):
  1. Recipient fields: To (always visible), CC/BCC (collapsible, chevron toggle)
  2. Subject field
  3. Rich text editor (Tiptap) — `min-h-[300px]`, fills remaining space
  4. Attachment drop zone + list (collapsible when empty)
  5. Signature selector (dropdown, Phase 5 feature — placeholder for now)

### Recipient Chips (D-27, D-28)
- **Format**: Inline chip per address: `Name <email@domain.com>` × (remove button)
- **Multiple**: Comma-separated input → converts to chips on blur/comma/Enter
- **Autocomplete**: Dropdown on focus/typing (debounced 200ms), keyboard navigable (↑/↓/Enter/Tab)
- **BCC**: Chips hidden from other fields' autocomplete context; visually distinct (subtle badge)

### Rich Text Editor — Tiptap (D-02, D-04)
- **Extensions**: StarterKit + Link + Image + Table + TaskList + TextAlign + FontSize + Color + Emoji + Placeholder + History + CharacterCount
- **Custom**: Signature insertion node (placeholder `{{signature}}` replaced on send)
- **Toolbar**: Two-row grouped layout:
  - Row 1: Bold, Italic, Underline, Strikethrough, | Font Size, Text Color, Highlight, | Heading (H1-H3), | Alignment (L/C/R/J)
  - Row 2: Bullet List, Ordered List, Task List, | Quote, Code Block, Horizontal Rule, | Table, Link, Image, Emoji, | Undo, Redo
- **Livewire sync**: Hidden `<textarea wire:model="body">` updated via Tiptap `onUpdate` callback
- **Paste handling**: Strip non-allowed tags; convert Word/Google Docs markup to clean HTML

### Draft Autosave (D-05, D-06, D-07, D-08)
- **LocalStorage key**: `openmail:draft:{compositionId}` — compositionId = UUID generated on composer open
- **Debounce**: 1500ms after last keystroke/change
- **Indicator**: Toolbar right side — "Saving…" (spinner) → "Saved just now" → "Saved 2 min ago"
- **Load priority**: IMAP Drafts folder (server) → merge with LocalStorage (newer wins by timestamp)
- **On send**: DELETE from IMAP Drafts (UID EXPUNGE), clear LocalStorage key
- **On discard**: Clear LocalStorage key, optional IMAP Drafts cleanup if previously synced

### Reply / Forward Quoting (D-09, D-10, D-11, D-12)
- **Structure**:
```html
<blockquote class="quote-block border-l-4 border-blue-200 pl-4 ml-4 my-2">
  <div class="quote-header text-xs text-gray-500 mb-1">
    On {formattedDate}, {senderName} <{senderEmail}> wrote:
    <button class="quote-toggle ml-2 text-blue-600 hover:underline" @click="toggle">Show quoted text</button>
  </div>
  <div class="quote-content" x-show="open" x-transition>
    {sanitizedQuotedHTML}
  </div>
</blockquote>
```
- **Collapsed by default** — user expands to see full history
- **Forward**: Same component, prepended with "-------- Forwarded message --------" header
- **Sanitization**: HTMLPurifier server-side → DOMPurify client-side (reuse `MessageSanitizer`)

### Attachments (D-13, D-14, D-15, D-16)
- **Drop zone**: `border-2 border-dashed border-gray-300 hover:border-blue-400 rounded-lg p-8 text-center`
- **Upload**: Immediate POST to `/api/composer/attachments` → returns temp ID + preview URL
- **List item**: Thumbnail (images) / icon (files) + filename (truncated) + size + × remove
- **Limits**: 25MB/file, 50MB total, MIME allowlist (images, PDF, Office, text, zip)
- **Lifecycle**: Temp storage (24hr TTL) → IMAP Drafts on autosave → IMAP Sent on send

### Undo Send (D-21, D-22, D-23, D-24)
- **Delay**: Configurable 5-30s (default 10s), stored in user settings
- **Toast**: Fixed bottom-right, `z-50`, slide-in animation, progress bar counting down
- **Action**: "Undo" button cancels pending send, moves message to Drafts (IMAP APPEND), shows "Moved to Drafts" confirmation
- **Database**: `pending_sends` table — `id`, `user_id`, `message_json`, `send_at`, `status` (pending/sent/failed/cancelled)

### Contact Autocomplete (D-25, D-26, D-27, D-28)
- **Source**: IMAP SEARCH `SINCE {30 days ago}` on Sent + Inbox folders → extract To/CC/From addresses
- **Cache**: DB table `contact_autocomplete_cache` — `email`, `name`, `last_used`, `frequency`, `expires_at`
- **Dropdown**: Max 10 results, grouped: "Recent" (frequency-sorted) + "All matches"
- **Selection**: Click or Enter/Tab adds as chip; comma in input creates new chip

### Keyboard Shortcuts
- `Ctrl/Cmd + Enter` → Send (primary action)
- `Ctrl/Cmd + S` → Save Draft (prevent default browser save)
- `Escape` → Close modal (prompt if dirty: "Discard changes?")
- `Tab` / `Shift+Tab` → Navigate fields + chips + editor toolbar
- `↑/↓` in autocomplete → Navigate suggestions

### Responsive Behavior
- **Desktop (≥1024px)**: Full modal centered, side-by-side toolbar rows
- **Tablet (768-1023px)**: Modal near-full-width (`m-4`), stacked toolbar rows
- **Mobile (<768px)**: Full-screen modal (`fixed inset-0 m-0 rounded-none`), bottom sheet style, toolbar collapsible

### Accessibility
- All form fields: `<label for="...">` + `id` matching
- Modal: `role="dialog" aria-modal="true" aria-labelledby="composer-title"`
- Focus trap in modal (Alpine.js focus management)
- Autocomplete: `aria-activedescendant`, `role="listbox"`, `role="option"`
- Chips: `role="listitem"`, remove button `aria-label="Remove {email}"`
- Editor: `contenteditable` with `aria-label="Message body"`, toolbar buttons `aria-pressed` for toggle states
- Toast: `role="alert" aria-live="polite"`
- Color contrast: All text ≥4.5:1, interactive elements ≥3:1
